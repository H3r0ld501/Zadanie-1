Python i C#
Wymagania

Python 3.x — https://python.org/downloads (zaznaczyć "Add to PATH")
.NET SDK — https://dotnet.microsoft.com/download

Uruchamianie Python
Dwuklik na plik .py lub w terminalu

Liczby dziesiętne wpisywać z kropką, nie przecinkiem (np. 3.5).

Uruchamianie C#
Bez instalacji — wklej kod na https://dotnetfiddle.net i kliknij Run.

Uwagi
Liczby dziesiętne wpisywać z kropką (np. 3.5, nie 3,5)
Kierunek konwersji temperatur wpisywać wielką literą (C lub F)
Operacje w kalkulatorze wpisywać jako znak (+, -, *, /)
